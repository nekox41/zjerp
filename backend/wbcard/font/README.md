# 维保卡字体

新生成器使用 `NotoSansSC-Regular.ttf`，由 Google Fonts 的 Noto Sans SC 可变 TrueType 字体在 wght=400 实例化得到静态字体，供 PDFBox 嵌入及子集化。原始来源：https://github.com/google/fonts/tree/main/ofl/notosanssc 。许可证见 `NotoSansSC-OFL.txt`（SIL Open Font License 1.1）。字体工具及原始可变字体仅保存在本地归档，不属于运行依赖。

旧 `SourceHanSerifSC-Medium.otf` 是历史 iText 方案资源，新生成器不使用它。
