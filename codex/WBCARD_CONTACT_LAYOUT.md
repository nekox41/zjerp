# 维保卡系统文字与联系信息修复

两条系统下划线分别只容纳一行，按第一行和第二行的真实宽度流排；两行不足时共同缩小字号，仍放不下则拒绝截断。避免在第一条下划线的区域内堆叠多行。

项目负责人独立录入，选择当地联系人仅带入电话，不覆盖负责人。PDF电话统一增加0371-53392119/前缀，已有相同前缀不重复添加。两端日期统一为yyyy年MM月dd日，并以“至”直接连接，例如2026年11月01日至2027年10月31日。

独立生成页面与项目资料页面复用同一系统选项清单，均可多选，不要求手动填写维护系统。
