# 众基消防 · 工作台界面规范

## 目标
便捷、清晰、可靠：让日常录入、查找和核对合同更快。所有后续新页面遵循此规范，旧页面逐步迁移。

## 视觉语言
- 浅灰蓝画布 `#f4f6fa`，白色内容卡片，深蓝黑正文 `#17243b`，次级文字 `#65748b`。
- 主色使用稳重蓝 `#2458d3`，少量消防橙 `#ed7043` 用于品牌点缀；警告、成功与危险同时使用文字，不能只靠颜色。
- 页面标题24px、正文14px、说明12px；间距采用4/8/12/16/24/32px，内容卡片圆角12px，边框代替重阴影。
- 金额右对齐并以人民币两位小数展示，数据库保留历史精度；日期统一 YYYY-MM-DD；缺失值用“未填写”，待确认事项明确显示。

## 设计 Token 实现
- 颜色、字体、间距、圆角、焦点环和动效时长统一维护在 `src/assets/styles/tokens.scss`。
- 众基业务样式通过 CSS 自定义属性引用 Token；页面不得重复定义同义色值或间距变量。
- 修改视觉规范时，先更新 Token 与本文件，再调整具体组件；旧页面逐步迁移，不要求一次性改写通用 RuoYi 后台。

## 页面与交互
- 顶部是栏目名称、简短说明和唯一主要动作。筛选栏靠近列表，输入回车查询，提供清空和刷新。
- 桌面使用高信息密度的表格，名称为详情入口；不显示无意义的装饰数据。分页由服务端完成。
- 详情与编辑在侧边抽屉中完成，分为基本信息、归属、付款计划、附件和备注，底部固定操作。查看和编辑明确区分。
- 必填项有标签、明确错误提示；保存防重复点击，未保存离开要确认；删除必须确认且说明对象。
- 关联中间人通过远程搜索选取，不一次加载全部记录；保留原有选择显示。付款计划使用可增删的阶段行，显示计划合计。
- 加载、空结果、失败和禁用都要有明确状态；请求失败可重试，避免默默展示旧数据。筛选变化须重置分页。

## 可访问性与响应式
- 控件带可读标签，支持键盘操作和可见焦点。按钮文本表达动作，触控目标至少32px。
- 900px以下筛选和表单改为单列，抽屉接近全屏；表格保持横向滚动，避免压缩关键字段。
- 支持系统减少动态效果偏好；不使用大面积动画和无意义渐变。

## 性能与实现
- 复用 Element Plus、共享业务样式与组件，路由懒加载，不引入额外大型界面依赖。
- 服务端分页、搜索按需触发，列表不预加载附件内容；先获取单条详情再展示表单。
- 颜色、间距与圆角以共享样式变量维护；新模块统一使用 `src/assets/styles/zhongji.scss`。
- 权限由角色决定，前端隐藏按钮只是交互，后端必须再次检查；金额和业务规则由后端最终校验。

## 项目工作台
- 五类项目使用同一列表组件，详情是独立工作台，以基本、详细、登记、问题、备注、计划和报账七个分区组织信息。
- 每个分区单独保存，切换或离开前提示未保存修改；版本冲突要提示刷新，不能静默覆盖他人更新。
- 新项目保存成功才分配正式编号。历史未确认的合同、类型和编号必须显示状态，原始数据可追溯。
- 报账只读展示项目合计、用户汇总及分页明细，账面历史汇总与实际明细分开，不隐藏差异；财务访问单独由角色授权。

## 财务与手机选择
- 财务工作台按概览、合同、项目、账户、流水、开票组织；报账、开票和现金收支分开呈现，标签明确金额口径。
- 手机关联选择使用可触控搜索弹窗，打开提供有限候选，支持单字及中文输入法；加载、失败重试与无结果分别展示，选中后立即清除必填错误。
- 发票登记优先展示号码、日期、客户、价税合计和关联合同/项目。有效记录不直接改写，作废需原因、保留历史；资金转账明确提示成对入账及成对作废。
